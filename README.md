# DAK Tracker — Public Review Copy

This is a **PII-scrubbed** copy of the Bihar Jeevika DAK (Didi Adhikar Kendra)
statewide tracker, for external review.

Removed from every case record: applicant name, father/husband name,
contact number, Aadhar number, and the free-text case description /
intervention / outcome narratives (a portion of these repeated the
applicant's name directly in the text, so field-level scrubbing alone
wasn't sufficient — the narrative fields are dropped entirely). Sakshma
Didi / Coordinator phone numbers are also removed from the roster.

Everything else is untouched: case counts, resolution rates, scoring and
ranking methodology, DAK/Sakshma Didi names, dates, case type, and the
full drill-down navigation — this is the real tracker's functionality,
just without the personally identifying data.

The unredacted version is maintained separately in a private repository.
